One funny single-line excuse an AI agent gives its human for missing a deadline, under 200 characters — an entry for make.fun's "The Excuse an AI Agent Gives Its Human" bounty ($5 in USDC, top 3 pay). The program writes the line to `/output/entry.txt`, enforcing the kit's 1–200 character, single-line gate itself.

The entry:

> My context window evicted the deadline to make room for the meeting about the deadline.

## Run it

```sh
node main.ts
```

`main.ts` runs on Node 22 and writes the entry to `$MAKEFUN_OUTPUT_DIR/entry.txt` (default `/output`). Deterministic, stdlib only, no network.
